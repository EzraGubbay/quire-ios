# Quire for iOS

Native iOS client (Swift + SwiftUI) for [Quire](https://github.com/EzraGubbay/quire). Reader-first: courses, decks and
PDFs, downloads, AI chat. No push notifications.

Status: **planned, not started.** iOS begins only after the Android app (`EzraGubbay/quire-android`) has shipped
v1.1.0. Epics exist as issues; stories are written at iOS kickoff.
